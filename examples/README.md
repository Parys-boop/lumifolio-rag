# Acervo de demonstração

Os quatro documentos são materiais originais elaborados para o Lumifólio. Eles podem ser carregados e compartilhados para reproduzir esta demonstração. Os procedimentos da disciplina fictícia, seus identificadores e suas fichas servem ao exercício. Os PDFs contêm texto selecionável.

| Arquivo | Conteúdo |
| --- | --- |
| `pln-e-embeddings.pdf` | Embeddings, paráfrases e similaridade de cosseno |
| `pratica-de-rag.pdf` | Chunking, sobreposição e conferência de fontes |
| `guia-do-laboratorio.txt` | Procedimentos e identificadores fictícios do exercício |
| `cuidados-com-fontes.txt` | Autorização, privacidade e leitura crítica |

Os PDFs já estão prontos para uso. Para recriá-los após editar o material, instale ReportLab em um ambiente de edição e execute `python examples/gerar_pdfs.py`.
